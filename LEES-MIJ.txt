C&B WEBSITE + DASHBOARD

Dit pakket bevat de bestaande C&B-website en een dashboard op /beheer/.
Het gebruikt jouw bestaande Cloudflare Worker en D1-database.

START HIER
Open DASHBOARD-INSTELLEN.md voor de volledige stappen.

1. Voeg de dashboardtabellen toe met migrations/0002_dashboard.sql.
2. Stel Cloudflare Access in voor twee persoonlijke e-mailadressen.
3. Voeg de vier toegangsvariabelen toe bij je bestaande Worker.
4. Upload de bestanden via je bestaande GitHub-repository.
5. Controleer de nieuwe publicatie en log in via /beheer/.

De code is lokaal getest, maar is nog niet op jouw accounts gepubliceerd.
Er zitten geen wachtwoorden, echte klantgegevens of testsessies in dit pakket.

Inbegrepen: aanvragen bekijken en zoeken, statusfilters, interne notities,
activiteitenlog en een technische controlepagina voor Upside.

De publieke websitebestanden zijn meegenomen uit de opgehaalde bronversie.
Heb je deze daarna aangepast? Behoud jouw nieuwere index.html, style.css,
script.js en assets; die bestanden hoeven voor het dashboard niet te wijzigen.

Testen met Node.js 24: npm test
Publieke bestanden bouwen: npm run build

Een statuswijziging verstuurt geen e-mail en bevestigt geen afspraak.
